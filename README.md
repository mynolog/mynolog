## 👋 About Me

안녕하세요! 작은 불편도 놓치지 않기 위해 UI 흐름과 디테일을 함께 설계하는 프론트엔드 개발자 `이민호`입니다.

매장 운영과 고객 응대 경험을 바탕으로 사용자 니즈에 민감하게 반응하며, React, Next.js, Vue.js 기반의 프로젝트를 통해 UI 설계, 상태 관리, API 연동 등 실전 경험을 쌓아왔습니다.

또한, 직접 만든 블로그와 다양한 사이드 프로젝트를 통해 **기술에 대한 고민과 성장**을 기록하고 있습니다.
